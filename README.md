# Geometry and diffusion: a static mathematical presentation

Open index.html. All content, formula fonts, figures and Three.js runtime assets are local. No backend or CDN is required.

Read continuously or use Present mode. Keys Left/Right move between chapters; Escape exits presentation mode. Each of four embedded scenes supports orbit, zoom, pan, playback speed, pause and a scrubber. A scene stops rendering when it is off screen.

The site contains only the expository presentation and its assets. It does not include the private main manuscript, private repository history or the earlier SymPy annex.
